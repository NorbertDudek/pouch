## [0.4.1] - 2026-11-24

First public release on GitHub.

### Added

- Firefox add-on (Manifest V3, Firefox 140+): one-click save, search, edit, undo delete,
  full-tab view, pagination, light/dark theme.
- Optional self-hosted sync server (PHP 8.0+, SQLite) with token authentication.
- Android app (Delphi / FireMonkey): Share → Pouch, search, edit, swipe to delete, manual add, sync.
